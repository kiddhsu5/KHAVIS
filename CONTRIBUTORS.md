## How to add yourself

After your first merged PR, add yourself in one of three ways:

### Option A: PR the README

1. Open a PR to `CONTRIBUTORS.md`
2. Add a line under the appropriate section:
   ```markdown
   - [x] @your-handle ([#PR](https://github.com/kiddhsu5/KHAVIS/pull/N)) 💻 ⚠️
   ```
3. A maintainer will merge and the bot will regenerate the table

### Option B: Use the all-contributors CLI

```bash
# install once
npm install -g all-contributors-cli

# add yourself
all-contributors add your-handle code,doc,test

# regenerate tables
all-contributors generate
```

### Option C: Comment on your PR

After merging, leave a comment on the PR with `@all-contributors please add @your-handle for code`.
A maintainer-bot will open a follow-up PR.

# 文件庫：主題歸檔與來源追蹤

在工作台點「資料庫」，或直接開啟 `/database`。首頁保留入口，文件瀏覽與篩選在獨立頁面進行。

## 文件從哪裡來

文件庫合併最近 400 筆派工紀錄中的產物、各專案 `workspace/<project>/deliverables`、`output`、`outputs`，以及平台登記的交付文件。平台根目錄的 `deliverables`、`output`、`outputs` 也會掃描。相同實體路徑只計一次，文件內容與位置不會被搬移或修改。

有明確紀錄的文件保留原始對話串。只在磁碟找到、但沒有任務關聯的文件會標成「工作區文件（未連結來源任務）」，不會猜測某一輪對話就是來源。過期歷史路徑仍可保留記錄，但預覽與下載按鈕會停用。

## 自動按主題分類

內建規則依序檢查檔名、路徑、來源任務與可讀內容摘要，分類為學習與考試、品牌與行銷、財務與量化、部署與維運、開發與技術、研究與分析、專案與使用指南、其他文件。每份文件會顯示分類依據，例如「檔名：品牌」。

此版本採可解釋的規則分類，不呼叫付費模型，不是向量知識庫或完整語意檢索。MD、TXT、HTML、CSV、RST、DOCX、PPTX 可讀取有上限的內容樣本；PDF、圖片與其他格式主要依檔名、路徑和任務分類，未啟用 OCR。抽樣不是全量全文索引，分類可能需要後續調整規則。

## 篩選與更新

主題、檔案格式及搜尋文字可組合使用。搜尋包含檔名、路徑、來源任務、主題與已抽樣內容。沒有符合條件時會說明是篩選後無結果；API 錯誤則顯示錯誤與重試指引，不會偽裝成空文件庫。

頁面可手動重新整理；處於可見狀態時每 30 秒重新同步索引。所有分類都即時計算，內容樣本按檔案修改時間與大小快取。新增或修改文件後可重新整理查看。

## 安全與限制

沿用工作台既有的下載／預覽路徑白名單，掃描排除隱藏目錄、憑證副檔名、資料庫及 symlink，不執行文件內容。分類不代表文件已完成品質檢查。部署者仍需保護工作台入口與 API 權限；不要將私人工作台視為可任意公開的唯讀 Demo。

本次修復包含「全部類型」大小寫造成整頁空白、相同文件在主題及未分類區重複計數，以及只依任務 prompt 分類而漏掉無來源文件等問題。
